# Курсовая работа / Лабораторная работа: Объектно-ориентированное программирование на C++
**Тема:** Проектирование классов, управление памятью, Композиция и Агрегация.

## Описание проекта
Данный проект представляет собой программный модуль анимационной системы на языке C++, демонстрирующий основные принципы ООП, разницу между композицией и агрегацией, а также корректное управление статической и динамической памятью.

### Архитектура системы:
Проект находится в пространстве имён `motion` и включает в себя ключевые классы:
1. **`SourceFile` (Исходный файл):** Сущность, описывающая исходный файл изображения (путь к файлу, флаг доступности).
2. **`Image` (Изображение):** Класс графического элемента (название, координаты $x$ и $y$, коэффициент прозрачности от 0 до 100).
   * **Агрегация:** Содержит указатель на `SourceFile` (`SourceFile*`). Изображение не владеет файлом — `SourceFile` создаётся независимо и может существовать после уничтожения изображения.
   * **Правило пяти (Rule of Five):** Копирование явно запрещено (`= delete`), перемещение разрешено по умолчанию (`= default`).
3. **`Project` (Проект):** Класс анимационного проекта (название, разрешение, частота кадров, длительность).
   * **Композиция:** Управляет списком изображений. Время жизни изображений строго привязано к проекту: при уничтожении проекта автоматически уничтожаются все принадлежащие ему изображения.


## Требования к сборке
- **Система сборки:** CMake (версия 3.15 или выше).
- **Компилятор:** MSVC (Visual Studio 2022+), `g++` или `clang++` с поддержкой стандарта **C++17** (или выше).

- **ОС:** Windows, Linux или macOS.


### Компиляция и запуск

### 1. Сборка через CMake (Рекомендуемый способ для Visual Studio)
1. Откройте папку проекта в **Visual Studio**.
2. Дождитесь автоматической настройки CMake-кэша.
3. Нажмите **Сборка -> Пересобрать решение** (Rebuild Solution).
4. Запустите проект (клавиша **F5**).

### 2. Быстрая компиляция через командную строку (g++)
Для сборки всех файлов проекта можно выполнить команду в терминале:

```bash
g++ main.cpp image.cpp project.cpp source_file.cpp -std=c++17 -o oop_coursework
